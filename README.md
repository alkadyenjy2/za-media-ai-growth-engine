# ZA Media — AI Growth Engine

> AI-powered growth and operations systems for service businesses: capture → qualify → organize → follow up → learn.

## Portfolio case study

ZA Media is positioned as an **AI growth and operations system**, not a collection of disconnected automations. The product direction connects lead intake, AI qualification, CRM operations, follow-up, reporting, and continuous workflow improvement.

### Core operating model

```text
Lead / Inquiry
      ↓
Capture + Normalize
      ↓
AI Qualification
      ↓
CRM / Pipeline
      ↓
Follow-up + Escalation
      ↓
Growth Intelligence
```

### Product scope

- Lead operations setup
- AI qualification and scoring
- Follow-up automation
- Growth intelligence dashboards
- AI operations / workflow improvement

### Engineering

The repository is a React + Vite + TypeScript application with Gemini integration and supporting growth/positioning assets.

The repository currently contains the product implementation plus documented positioning and social-planning material. Deployment status is **not claimed as independently verified in this README**; the public repository is the source of truth for the implementation that is actually present.

### Evidence-first positioning

The project documentation explicitly avoids guaranteed-revenue or "fully autonomous growth" claims. The intended portfolio narrative is:

**Problem → System → Implementation → Verification → Improvement**

### Related proof

Rizkaha is documented as a flagship proof project for the broader ZA Media positioning. Claims about runtime results are intentionally separated from planned production-hardening work.
